## What changed, axis by axis

- **Style as a parameter**: 0.50 (base) -> 0.88 (winner). The style line in
  the prompt now drives the pick.
- **Refusal (never hallucinate)**: 0.00 everywhere before v3 -> 1.00 at
  the winner. The model refuses missing moments (guitar / piano / rain /
  group photo) in every style. Taught by SFT (v3), kept by GRPO.
- **Many files at once (multi-pick)**: 0.00 (v1) -> 1.00 (winner). One
  call returns 3 clips in order, all exact.
- **Stability**: 1.00 accuracy on both distractor sets, pairs agree 3/3.
  The pick does not flip when distractors change.
- **Exact windows (open generation)**: 0.00 at the winner (file right
  1.00, mean IoU 0.36). The one remaining gap — see below.

## The remaining gap, and the next lever

Exact (file, start, end) in open generation is 0.00 at the winner: the file
is always right (1.00) but the window is off by seconds (mean IoU 0.36).
GRPO's reward is clip-level (right clip / wrong clip), so it never
optimises window precision. Next lever, in order:
1. Grade the GRPO reward by window IoU (e.g. 1.0 exact, 0.5 for IoU > 0.5,
   0 otherwise) instead of 0/1 — same prompts, no new data.
2. Or an SFT round on exact windows (the 27 picks already carry exact
   ranges; the model needs more steps on them, not more data).
